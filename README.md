# Understory — site

The public page for **Understory**, a natural history of South Carolina for
iPhone. Plain static HTML, no build step, no dependencies. Published with
GitHub Pages from `main`.

The page mirrors the app's own design: the same paper (`#F4EDDE`) and ink
(`#2C261F`) the book is set in, letterpress capitals for labels, and EB Garamond
with IM Fell English for display.

`img/` holds screenshots of the app and the public-domain plates it is built
from. The app itself lives in a separate private repository.
